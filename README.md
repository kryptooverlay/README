# Finova Options (Preview Repository)

This is a placeholder repository for the TradingView Advanced Charts application request.

## What is Finova Options?

**Finova Options** is a simulated and gamified trading platform designed for educational purposes.

- All trades are executed using **virtual balances** only.
- No deposit or withdrawal features exist.
- There is **no handling of real money, cryptocurrencies, or financial services**.
- The platform is strictly non-commercial and for **training, testing, and entertainment**.
